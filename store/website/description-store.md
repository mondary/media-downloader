# PKMediaDownloader — website courant

**FR** — Télécharge. Garde. Découpe. Une app macOS native qui transforme un
lien en fichier : yt-dlp pour des milliers de sites, historique pour tout
retrouver, éditeur d'extrait local. Sans compte, sans upload. En cas d'échec,
Cobalt reste un lien de secours externe, sans envoi automatique de l'URL.

**EN** — Download. Keep. Trim. A native macOS app that turns a link into a
file: yt-dlp for thousands of sites, history to find everything again, a
local clip editor. No account, no upload. If a download fails, Cobalt stays
an external fallback link — the URL is never sent automatically.
