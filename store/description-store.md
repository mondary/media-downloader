## Description longue

### FR

**PKMediaDownloader** est un téléchargeur vidéo natif macOS basé sur yt-dlp. Collez une URL YouTube, Instagram, X/Twitter ou TikTok : le téléchargement démarre automatiquement, le fichier est converti en MP4 et copié dans le presse-papiers.

#### ✨ Fonctionnalités clés
- **Milliers de sites supportés** — via yt-dlp
- **Playlists YouTube** — détection automatique des URLs playlist
- **Auth réseaux sociaux** — support cookies pour Instagram, X/Twitter, TikTok
- **Conversion/merge MP4** — H.264/AAC
- **Auto-copie** — le fichier est copié dans le presse-papiers après téléchargement
- **Historique** — thumbnails et actions rapides
- **Trim vidéo** — couper, sauvegarder ou copier un extrait
- **Raccourci clavier universel** — active l'app depuis n'importe où (Cmd+Shift+6)
- **Icône menubar** — accès rapide
- **Auto-paste** — les URLs du presse-papiers sont détectées automatiquement

### EN

**PKMediaDownloader** is a native macOS video downloader powered by yt-dlp. Paste a YouTube, Instagram, X/Twitter or TikTok URL: the download starts automatically, and the file is converted to MP4 and copied to the clipboard.

#### ✨ Key features
- **Thousands of supported sites** — via yt-dlp
- **YouTube playlists** — automatic playlist URL detection
- **Social media auth** — cookie support for Instagram, X/Twitter, TikTok
- **MP4 convert/merge** — H.264/AAC
- **Auto-copy** — file copied to the clipboard after download
- **History** — thumbnails and quick actions
- **Video trim** — cut, save or copy an excerpt
- **Universal keyboard shortcut** — activate the app from anywhere (Cmd+Shift+6)
- **Menubar icon** — quick access
- **Auto-paste** — clipboard URLs are detected automatically
