# PKMediaDownloader — website courant

**FR** — Un lien devient un fichier sur votre Mac. Téléchargez avec yt-dlp,
retrouvez chaque vidéo dans l'historique et découpez un extrait. En cas
d'échec, Cobalt reste un lien externe de secours, sans transmission automatique.

**EN** — Turn a link into a file on your Mac. Download with yt-dlp, find
every video in history and trim a clip. If a download fails, Cobalt is an
external fallback link; no URL is sent automatically.
